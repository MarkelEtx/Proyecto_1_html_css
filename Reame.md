# Agencia VSF

## Descripción

Este proyecto consiste en el desarrollo de un prototipo web diseñado para ofrecer una experiencia de navegación sencilla, intuitiva y accesible. Su objetivo principal es presentar la información de forma organizada mediante diferentes páginas conectadas entre sí.

Está dirigido a los usuarios que necesitan una solución práctica para realizar las funciones que ofrece el proyecto. La propuesta busca cubrir una necesidad concreta mediante una interfaz clara, adaptable a distintos dispositivos y fácil de utilizar.

## Puesta en Marcha

El proyecto se puede visualizar directamente en el navegador web abriendo el archivo index.html, que actúa como página principal y permite navegar entre las distintas vistas del prototipo.

## Estructura del Prototipo

El prototipo está compuesto por tres páginas HTML que permiten acceder a las diferentes secciones de la web. La navegación entre ellas se realiza mediante enlaces internos.

- **index.html:** Página principal del proyecto. Presenta la información inicial y sirve como punto de acceso al resto de las secciones.
- **login.html:** Segunda pantalla del prototipo, dedicada a mostrar información o funcionalidades complementarias.
- **reserva.html:** Tercera pantalla, que amplía el contenido del proyecto y completa la experiencia de navegación.

## Tecnologías Utilizadas

- **HTML5:** Utilizado para estructurar el contenido y definir los elementos de cada página.
- **CSS3:** Empleado para diseñar la interfaz, aplicar estilos y organizar los elementos visuales.

## Enfoque Técnico

El desarrollo se ha planteado siguiendo una serie de principios básicos de diseño y maquetación web:

- **Diseño Mobile First:** La interfaz se diseña inicialmente para dispositivos móviles y se adapta progresivamente a pantallas de mayor tamaño.
- **Selectores CSS:** Se utilizan selectores básicos y combinados para aplicar estilos de forma organizada y específica.
- **Propiedades Display:** Se emplean diferentes valores, como `block`, `inline-block`o `flex`, según las necesidades de distribución de los elementos.
- **Organización del código:** Se mantiene una estructura clara y coherente para facilitar la lectura, el mantenimiento y las futuras modificaciones del proyecto.
